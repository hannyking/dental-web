# dental-web

Apex Oral Care（卓峰口腔護理）— modern Traditional Chinese dental clinic website built with Astro and Tailwind CSS.

## Getting started

Requires **Node.js 22.12+** (Astro 7).

```sh
npm install
npm run dev
```

| Command           | Action                                      |
| :---------------- | :------------------------------------------ |
| `npm install`     | Install dependencies                        |
| `npm run dev`     | Start local server at `localhost:4321`      |
| `npm run build`   | Build production site to `./dist/`          |
| `npm run preview` | Preview the production build locally        |

## Notes

- WhatsApp booking link placeholder: update `WHATSAPP_URL` in `src/data/site.ts`
- Clinic phone numbers and addresses in the same file are placeholders
